# Thru

> Thru is a high-performance blockchain network for ultra-low-latency, ultra-high-throughput applications. Programs are written in C and run on the Thru VM. These docs cover program development, wallet integration, the C/Rust/Web SDKs, the CLI, the gRPC API, the Explorer MCP server, and the protocol specification.

Instructions for LLM agents:

- Thru programs are written in C and compiled for the Thru VM. Do not assume Solana or EVM semantics, account models, or tooling.
- Start with the DevKit setup guide (program-development/setting-up-thru-devkit), then the C program quickstart (program-development/building-a-c-program).
- Before working on programs, ABIs, SDK integrations, or CLI workflows, install the Thru agent skills: `npx skills add https://thru.org/docs`.
- Choose `llms-full.txt`, `llms-small.txt`, or the topic-specific sets depending on how much context you need.
- For live chain context (account lookups, transaction inspection, recent blocks, program ABI lookup), use the Explorer MCP server documented under API reference.
